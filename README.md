# Bahama Mama Swimwear — Nuxt + Tailwind landing page

This repository contains a minimal Nuxt 3 + Tailwind 3 boilerplate for a landing page for Bahama Mama Swimwear, a made-to-order swimwear brand based in Grenada.

Quick start:

1. Install dependencies

   npm install

2. Run the dev server

   npm run dev

Notes:
- This is a starter layout with placeholder product images from Unsplash.
- Customize copy, colors, and images in the components and pages.
